GORILLA PATCHER WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open the folder.
3. Open index.html in a web browser to preview the website.
4. To publish it, upload index.html, style.css, script.js, and the assets folder to your website host (for example, a GitHub Pages repository or Netlify).

PICTURE GALLERY
- The three screenshots you provided are already included.
- Open Picture Gallery and choose Upload pictures to add more images.
- Pictures you upload are saved in that browser on that device.

NOTE
This is a front-end website preview and picture gallery. The login, headset verification, and patching controls are informational/demo UI only. It does not connect to Meta, collect account tokens, or modify Gorilla Tag files.
